# ShopnSwap

**ShopnSwap** is a dynamic marketplace platform where users can **buy**, **sell**, **swap**, and even **donate** products. Whether you want to declutter, trade items, or find great deals, ShopnSwap provides a flexible and community-driven environment.

---

## ✨ Key Features

- **Buy & Sell Products**  
  List your products for sale or browse listings to purchase from others.

- **Product Swapping**  
  Trade your items with others—no money needed.

- **Product Donation**  
  Give away items you no longer need to people who do.

- **User Authentication**  
  Secure sign up, login, and profile management.

- **Product Search & Filtering**  
  Easily find products by category, price, and swap/donation availability.

- **Chat/Messaging (optional)**  
  Built-in messaging to negotiate or arrange swaps (if implemented).

---

## 🛠 Tech Stack

- **MongoDB** – NoSQL database for storing user and product data.
- **Express.js** – Backend server and RESTful API.
- **React.js** – Frontend user interface.
- **Node.js** – Runtime environment for the backend.

> Full **MERN** stack implementation for a seamless development experience.

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/shopnswap.git
cd shopnswap
```

### Backend Setup
 ```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

### Environment Variables
```bash
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```
